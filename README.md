# Cheer Stand — By CheerDeb

เกมเว็บจำลองการเชียร์และแปรอักษรบนสแตนด์ โรงเรียนเทพศิรินทร์
ธีม 8-bit สีเขียว–เหลือง

ผู้เล่นสมัคร/เข้าสู่ระบบด้วยเลขประจำตัว 5 หลัก เล่น 8 รอบ เก็บคะแนนเต็ม 2,400 คะแนน
สามารถเริ่มเล่นใหม่เพื่อทำคะแนนสูงสุดได้ตลอดเวลา และระบบจะบันทึกประวัติการเล่นทุกครั้ง
มีหลังบ้านผู้ดูแล (Admin) แสดงคะแนนสด (Live Score) ในรูปแบบกราฟเปรียบเทียบ และหน้าจัดการผู้ใช้พร้อมดูประวัติการเล่นรายบุคคล

## การปรับปรุงล่าสุด (ตาม fix.txt)

1. **เวลาตอบคำถามจังหวะพลิกเพลท**
   - ปรับเวลาการตัดสินใจจาก 5 วินาที เป็น **15 วินาที**
2. **นำสีแดง/เขียวออก และใช้การกดยืนยันเพลท**
   - นำสีแดงและสีเขียวบอกถูก/ผิดแบบเรียลไทม์ออก เพื่อความสมจริงในการเชียร์
   - ผู้เล่นคลิกพลิกเพลท 1–6 บนแผง 3x3 จนครบ แล้วกดปุ่ม **“ยืนยันเพลท 3x3”**
3. **วันที่และตำแหน่งที่นั่งบนกระดาษโค้ด**
   - นำข้อความเดิมออก และแสดงเป็น **วันที่ปัจจุบันที่เล่นจริง** (เช่น วันที่ 5 พฤศจิกายน 2569)
   - แถวที่นั่งสุ่มอักษร **A–Y** และตัวเลข **1–50** (เช่น B14, M1, K25)
4. **ใบโค้ดประจำตัวในแต่ละเกม**
   - ผู้เล่น 1 คนจะได้ใบโค้ดชุดเดียวกันตลอดการเล่น 8 รอบในตานั้น
   - เมื่อกดเริ่มเล่นใหม่ในรอบถัดไป ระบบจะสุ่มโค้ดและที่นั่งใหม่ให้เรื่อยๆ
5. **จำนวนรอบการเล่น**
   - ปรับลดเหลือ **8 รอบ** รวมคะแนนเต็ม 2,400 คะแนน
6. **นำคำสั่งม่านออก**
   - ตัดเหตุการณ์และคำสั่งเกี่ยวกับม่านออกทั้งหมด เหลือเพียง **“เปิดจังหวะ”** และ **“ปิดจังหวะ”**
     - สั่ง “ปิดจังหวะ” = พลิกเพลทครึ่งนึง (เปิดครึ่ง)
     - สั่ง “เปิดจังหวะ” = พลิกเพลทไปเลย (เปิดเต็ม)
7. **คำสั่งสตาฟขนาดใหญ่พร้อมการแจ้งเตือน**
   - แบนเนอร์คำสั่งสตาฟแนวนอนตรงกลางจอขนาดใหญ่ขึ้นอย่างชัดเจน
   - มีไฟกะพริบแจ้งเตือน (Beacon Pulse) และเสียงเอฟเฟกต์แจ้งเตือนเมื่อมีคำสั่งใหม่
8. **นำข้อความ 10 รอบ 3000 คะแนน 1 นาทีต่อตา ออก**
   - ลบข้อความดังกล่าวออกจากหน้าแรกและหน้าแนะนำภารกิจ
9. **หน้าเข้าสู่ระบบของผู้ดูแล (Admin)**
   - ลบข้อความที่ระบุว่าผู้ใช้คือ admin ออก และนำค่าเริ่มต้นในช่องกรอกออก ไม่ให้ผู้ใช้งานทั่วไปทราบ
10. **การเชื่อมต่อ Supabase และ Vercel**
    - มีไฟล์ `.env.example`, `supabase_schema.sql`, `vercel.json` และ `api/index.js`
    - รองรับการเข้าเล่นและบันทึกข้อมูลจริงจากทุกที่ผ่าน Vercel และ Supabase

## การเชื่อมต่อ Supabase & Vercel เพื่อเปิดให้เล่นจากทุกที่

### 1. ฐานข้อมูล Supabase
1. สร้างโปรเจกต์ใหม่ที่ [Supabase](https://supabase.com/)
2. ไปที่เมนู **SQL Editor** แล้วคัดลอกคำสั่งใน `supabase_schema.sql` ไปวางแล้วกด **Run**
3. คัดลอก Project URL และ anon/service_role key
4. สร้างไฟล์ `.env` ในโฟลเดอร์โปรเจกต์ (หรือตั้งค่าใน Vercel):
   ```env
   SUPABASE_URL=https://your-project.supabase.co
   SUPABASE_KEY=your-supabase-key
   CHEER_ADMIN_PASSWORD=1234
   ```

### 2. นำขึ้น Vercel (Vercel Deployment)
1. ติดตั้ง Vercel CLI หรือเชื่อมต่อ Git Repository กับ [Vercel](https://vercel.com/)
2. ตั้งค่า Environment Variables ใน Vercel Dashboard:
   - `SUPABASE_URL`
   - `SUPABASE_KEY`
   - `CHEER_ADMIN_PASSWORD` (ค่าเริ่มต้น 1234)
3. สั่ง Deploy (`vercel --prod`) ทุกคนจากทุกที่จะสามารถเข้าเล่นผ่านโดเมนของ Vercel และข้อมูลจะถูกบันทึกจริงลงใน Supabase ทันที
